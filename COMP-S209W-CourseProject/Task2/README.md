# Task 2 – Heap and Heap Sort

## Description
This task is a self-study implementation for COMP S209W.

The chosen topics are:
- Data Structure: Heap
- Algorithm: Heap Sort

The Python program demonstrates the implementation of a max heap, including insertion and extraction operations, and also demonstrates heap sort for sorting a list of values.

## Files
- `heap_study.py` – Python implementation of heap and heap sort

## Main Features
- Max heap implementation
- Insert operation
- Extract maximum operation
- Heapify operation
- Heap sort algorithm
- Demonstration output in terminal

## Concepts Covered
- Data structures
- Heap as an abstract data type
- Heap operations
- Sorting algorithms
- Time complexity analysis

## How to Run
1. Open terminal in the `Task2` folder
2. Run:
   `python heap_study.py`

## Expected Output
- Heap insertion process
- Heap content after each insertion
- Extracted maximum value
- Original list before sorting
- Sorted list after heap sort
