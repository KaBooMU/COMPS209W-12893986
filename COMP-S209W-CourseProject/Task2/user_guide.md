# Task 2 User Guide

## Topic
Heap and Heap Sort

## Purpose
This task demonstrates a max heap data structure and the heap sort algorithm.

## Steps to Use

### 1. Open the program
- Open terminal or command prompt
- Change directory to the `Task2` folder

### 2. Run the file
Run:
`python heap_study.py`

### 3. Observe the output
The program will display:
- values being inserted into the heap
- the heap after each insertion
- the maximum value extracted from the heap
- the original unsorted list
- the final sorted list

## Program Functions
- `MaxHeap` class implements the heap data structure
- `insert()` adds values to the heap
- `extract_max()` removes the largest value
- `heapify()` restores the heap property
- `heap_sort()` sorts a list using the heap method

## Notes
- This program is designed for demonstration and learning purposes
- The sorted result is shown in ascending order
