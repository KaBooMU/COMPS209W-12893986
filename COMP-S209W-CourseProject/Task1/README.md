# Task 1 – Smart Restaurant System

## Description

Task 1 implements a restaurant ordering system using Python object-oriented programming.

The program simulates a restaurant workflow where customers can order food items, tables are assigned, and the system calculates the total bill.

## Features

Customer Management
- Store customer name and phone number

Menu System
- Display available food items
- Store item category and price

Order System
- Add menu items to an order
- Track order status
- Calculate bill

Table Management
- Assign table
- Release table
- Display table status

## OOP Concepts Used

- Classes
- Encapsulation
- Inheritance
- Methods
- Object interaction
